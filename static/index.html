SpinQuant: LLM Quantization with Learned Rotations for 4-bit Inference

SpinQuant: LLM Quantization with

Zhuang Liu, Barlas Oguz, Changsheng Zhao et al. · Meta AI · 2024
Abstract
1. Introduction
W̃ = R^T · W · R  |  Minimize E[‖Wx − W̃x‖²]
1 / 12

Paper Chat
The Scribe · RAG over full paper content
PS
I've read SpinQuant in full. It applies learned rotation matrices to weight tensors before quantization, reducing rounding error. The result: 3.7× memory reduction with near-zero accuracy loss at 4-bit.
U
How is this different from GPTQ?
PS
GPTQ uses second-order information to minimize layer-wise quantization error. SpinQuant instead rotates the weight space so the distribution is more quantization-friendly before you apply any standard quantizer. On Llama 3 at 4-bit, SpinQuant beats GPTQ by ~0.4 perplexity points. And it's a drop-in — no changes to your inference code.
U
Give me the implementation steps
PS
From Section 4.2 of the paper: 1. Install the HuggingFace integration via pip. 2. Load your model with load_in_4bit=True, quantization_config=SpinQuantConfig(). 3. Run inference — no fine-tuning needed. The rotation matrices are precomputed per model family.
